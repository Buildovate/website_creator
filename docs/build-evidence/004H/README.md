## What changed in the actual request chain

The prior report identifies img.story-finished as LCP, with a document → 89,695-byte CSS → 87,446-byte font chain (217ms actual trace chain; simulated LCP 5.272s). It also requests an 88,332-byte opening still/video poster beside the 65,365-byte finished still, and 147,889 bytes of Leaflet JS. The render-blocking insight estimates 1,110ms savings; unused CSS 72,159 bytes / 440ms and unused JS 122,970 bytes / 600ms. These are report estimates, not additive measured savings.

The finished hero is now a parser-discoverable AVIF/WebP picture, with media-specific responsive srcsets and matching high-priority preload. Phone selects 720w even at DPR 3; desktop selects 1440w. The AVIF phone asset is 11,193 bytes (11,493 with local response overhead). The competing opening image and video poster requests are removed from this Roofing path. Uploaded stills and static-hero routes retain their existing content.

First-screen styles are generated from the same full stylesheet sources and inlined. The LCP PerformanceObserver gates the remaining CSS/scripts; frame blobs and motion code start after the still's recorded LCP. Full styles are appended after critical styles to preserve the final cascade. A bounded paint fallback covers unsupported LCP APIs, missing images, hidden tabs and restored off-hero scroll positions. Native no-JS CSS/content remains available. Leaflet is omitted when no project-data map exists. Both final Lighthouse reports list zero render-blocking requests and identify the optimized 720w img.story-finished as LCP (about 1.2s).

Attempt 1 exposed a 0.0538 layout shift from the unstyled disclosure changing the hero's auto margins, plus the pre-existing smaller shift. Including the disclosure's final styles in the initial CSS removed that extra shift. [Final real-browser request order, observed CLS, DPR-3 asset selection and cold reduced-motion checks](final/request-chain.json) covers the homepage and v3 service hero. All tested CSS/motion/frame requests begin after the recorded hero LCP; reduced motion requests no sequence or video.
