04 / GOOD QUESTIONS

Your rekeying questions.

Rekeying / work detail
How is changing the key different from replacing the lock?

Resetting a compatible cylinder changes which key operates it while retaining the surrounding hardware. Worn or incompatible hardware may call for replacement instead.

Can my exterior doors use one key?

Some cylinders can share a key pattern, but their keyways must be compatible. Show the technician each door before deciding on a common-key arrangement.

What should I bring to a rekeying appointment?

Have the existing keys, a list of doors and the number of new keys needed. For work in Oxnard, QA Locksmith also confirms who is authorized to change access.
