# Conversion Playbook — Contractor Trade Sites

Directive rulebook for Codex when building premium contractor websites (roofing first; then HVAC, plumbing, patio covers, remodeling, and other trades). Distilled from KlientBoost guides. Source tags: **[1]** layout, **[2]** design tips, **[3]** copy, **[4]** headlines, **[5]** CTA copy.

## Product constraints (always)

- Hero and service imagery: designed / AI-generated only — never real contractor photos.
- Never invent claims. Stars, years in business, license #, warranty, “#1,” awards, job counts come from contractor profile fields. If empty → hide the element.
- Never mention SiteForge, Launch Window, or $750 on customer-facing pages.
- CTA labels need not be “Get my free estimate.” Match offer intent (estimate, inspection, emergency, financing). Prefer first-person where it fits **[5]**.

---

## 1) Page layout order

Copy before pixels. One primary conversion goal per page. Attention ratio near 1:1 — don’t scatter competing CTAs or leaky nav **[1][3]**.

### Trade homepage (recommended order)

1. **Hero (above the fold)** — Headline + subhead (what/who/how), hero visual that shows the finished job outcome, primary CTA, optional phone click-to-call, optional trust chips from profile only **[1][3]**.
2. **Trust strip** — Logos, ratings, licenses, years, insured/bonded — only fields that exist **[1][3]**.
3. **Problem / pain / signs** — 3 biggest homeowner pains for the trade (leak, bill spike, unsafe system, ugly patio, etc.) **[3]**.
4. **Offer / services grid** — Benefit-led cards; features support benefits, not the reverse **[1][3]**.
5. **How it works** — 3–4 concrete steps (call → inspect → quote → build) **[3]**.
6. **Proof / reviews** — Dedicated section + sprinkle near CTAs; real names/photos only if provided **[1][2][3]**.
7. **Before / after or project gallery** — Designed visuals OK; caption outcomes, not “Service illustration” **[1][2]**.
8. **Who we serve / areas** — Cities or homeowner types if true **[3][4]**.
9. **FAQ** — Objection killers (cost, timing, mess, permits, financing) **[3][5]**.
10. **Final CTA** — Same goal, restated in different words + different benefit angle **[1][3][5]**.

### Service-detail page (e.g. Roof Repair, AC Tune-Up)

1. **Hero** — Service-specific UVP (offer + benefit + sparkle), designed hero, primary CTA + phone **[1][4]**.
2. **Trust strip** — Same rules as homepage **[1]**.
3. **Signs you need this / problem** — Skimmable bullets **[3]**.
4. **What’s included** — Benefit headlines + short feature bullets; no paragraph walls **[1][3]**.
5. **Process** — 3–4 steps for this service **[3]**.
6. **Proof** — Reviews mentioning this service if available; else general proof **[1][3]**.
7. **Before / after** — Outcome visual for this service **[1]**.
8. **Financing / warranty / guarantees** — Only if profile has them **[3]**.
9. **FAQ** — Service-specific objections **[3]**.
10. **Final CTA** — Restate differently; optional secondary soft CTA (call) only if it supports the same goal **[1][5]**.

Skip empty sections. Never leave a beige void with one boxed photo and a caption.

## 2) Visual design rules

- **Hierarchy:** Contrast, scale, balance, repetition. Headlines bold/large; body quiet. Emphasize headlines, buttons, forms, testimonials — not paragraphs or decorative chrome **[1][2]**.
- **Emphasis:** Emphasize everything = emphasize nothing. CTA must out-compete imagery (don’t let a bright photo steal the button) **[2]**.
- **Directional cues:** Vertical flow for scroll; arrows sparingly toward primary CTA; prefer alternating section backgrounds over hard horizontal “stop” borders **[2]**.
- **Whitespace:** Z-path for visual pages; F-path for copy-heavy. Let sections breathe; don’t fill with abstract shapes **[1][2]**.
- **Imagery:** Every visual adds context — finished roof, happy dry attic metaphor, clean install — not stock filler or “illustration” captions **[1]**. Designed/AI imagery must look premium and specific to the trade.
- **Motion:** Subtle, purposeful (gentle hero motion, scroll reveals, soft transitions). No noisy loops that fight the CTA **[2]**.
- **Rhythm:** Consistent colors, type, card styles, button styles repeated down the page **[2]**.
- **Mobile:** Stack vertically; CTA reachable; tap targets large; phone sticky/secondary OK if primary goal stays clear **[1][2]**.
- **Attention:** Prefer one primary button style; ghost/secondary for call only. Clean chrome — don’t recreate full marketing-site nav noise on conversion-focused service pages **[1]**.

## 3) Copy rules

- Single goal. Every sentence earns a click toward it **[3]**.
- Customer POV, second person (“you”), contractions, short sentences. No industry sludge **[3]**.
- UVP answers **what / who / how** in hero. Crystal clear > clever **[3][4]**.
- Benefits over features. Features support benefits **[1][3]**.
- Concrete: numbers, times, materials, neighborhoods — only from profile or approved facts. Ban empty words: solutions, synergy, premier, all-in-one, leader (unless profile proves it) **[3]**.
- Skimmable: one idea per block, bullets, visual hierarchy, repeated patterns **[3]**.
- Message match: if ads/SEO target “emergency roof leak [city],” hero must say that **[3]**.
- Social proof language from real reviews when available; never fabricate quotes **[3]**.
- Final section ≠ copy-paste of hero — new angle, same promise **[3][5]**.
- Medium length (roughly 200–500 words of unique copy) fits most trade service pages; high-ticket full replacements can go longer if skimmable **[3]**.

## 4) Headline formulas + examples

**Formula:** `[OFFER] + [BIG PROMISE] + [SPARKLE]` **[4]**  
Also: positive tone over “Don’t / Tired of / Worried about” **[4]**. Subhead qualifies the H1 **[4]**.

### Roofing examples (8–10)

1. Roof repairs that stop the leak today — not next week  
2. New roofs built to outlast the next storm season  
3. Same-week roof inspections for homeowners who want a straight answer  
4. Storm-damage roofs replaced with materials that match your HOA  
5. Leak diagnosis in one visit — photo report before you decide  
6. Roofers who leave the jobsite cleaner than they found it  
7. Flat-roof specialists for commercial buildings that can’t afford downtime  
8. Emergency tarp-to-repair so one storm doesn’t become two  
9. Energy-smart roofing that lowers attic heat and cooling bills  
10. Local roofing, licensed and insured — proof upfront, price in writing  

### Adapt per trade (swap offer + promise + sparkle)

| Trade | Pattern |
|-------|---------|
| HVAC | AC that cools every room — tune-ups before the heat wave hits |
| Plumbing | Drain clearing that lasts — camera-verified, not guesswork |
| Patio covers | Shade you’ll actually use all summer — engineered for wind and HOAs |
| Remodeling | Kitchens finished on a date you can plan around — fixed-scope bids |
| Electrical | Panel upgrades that unlock EV chargers without the mystery invoice |
| Solar | Power bills cut with a system sized for your roof — not a one-size pitch |
| Painting | Crisp exteriors that still look new after rainy season |
| Landscaping | Yards designed for weekend living — irrigation that doesn’t waste water |
| Concrete | Driveways leveled and sealed so cracks don’t spread next winter |
| Windows | Quieter rooms and lower drafts — install in days, not weeks |
| Fencing | Privacy fences that stay plumb through Santa Ana winds |
| Pest control | Attic-to-crawl inspections that find the nest, not just the symptoms |
| Garage doors | Quiet openers and panels that fit your curb appeal |

Truth rule: location, license, speed, and “#1” only if profile supports them **[4]**.

## 5) CTA copy rules + contractor examples

Follow: intent → single goal → strong verb → value → objection → short (3–6 words) → restate differently at bottom **[5]**. Prefer first-person (“my/me”) when natural **[5]**. Use click-trigger microcopy under buttons (free, no obligation, reply in X hours — only if true) **[3][5]**.

**Do:** Get, Book, Schedule, Claim, See, Unlock, Start my…  
**Avoid as sole label:** Submit, Learn more, Click here, Request this service (vague, effort-heavy) **[5]**.

### Example button labels

| Intent | Primary CTA | Click-trigger ideas (if true) |
|--------|-------------|-------------------------------|
| Estimate | Get my free estimate | No obligation · Reply within 1 business day |
| Inspection | Book my roof inspection | Photo report included |
| Emergency repair | Get emergency help now | 24/7 storm line · Same-day tarp when available |
| Financing | See my financing options | Soft credit check · Decisions fast |
| Replacement quote | Get my roof replacement quote | Fixed-scope proposal |
| HVAC tune-up | Schedule my tune-up | Before-season slots |
| Plumbing camera | Book my camera inspection | Know before we dig |
| Callback | Call me back today | Average response under 2 hours |

Bottom CTA examples (same goal, new angle): “Stop the leak before it hits the drywall — get my free estimate” / “Ready for a number in writing? Book my inspection.” **[5]**

## 6) Pass / fail checklist (screenshot review)

Use on homepage and service-detail screenshots. Fail any critical item = revise before shipping.

1. **[ ]** Single primary conversion goal is obvious within 3 seconds **[1][3]**
2. **[ ]** Hero has H1 + qualifying subhead + CTA (not headline alone) **[1]**
3. **[ ]** H1 states offer + benefit (not a vague mood line) **[3][4]**
4. **[ ]** Subhead answers how / who without jargon **[3][4]**
5. **[ ]** Primary button stands out vs background and imagery **[2]**
6. **[ ]** CTA uses strong verb + value (not “Request this service” / “Submit”) **[5]**
7. **[ ]** Optional click-trigger under CTA if space allows **[3][5]**
8. **[ ]** Trust signals present when profile has them; nothing faked **[1][3]**
9. **[ ]** Problem/signs or pain section appears before deep feature dumps **[3]**
10. **[ ]** Benefits lead; features support (no paragraph wall “What’s included”) **[1][3]**
11. **[ ]** Dedicated proof/reviews section exists (or honest omission if zero reviews) **[1]**
12. **[ ]** Visuals add context; no useless “Service illustration” caption energy **[1]**
13. **[ ]** Section backgrounds alternate or otherwise invite scroll (no hard “done” fences) **[2]**
14. **[ ]** Final CTA restates value differently from hero **[1][5]**
15. **[ ]** Visual hierarchy: skimable H2s, short blocks, bullets **[2][3]**
16. **[ ]** Emphasis reserved for headlines/CTAs/proof — not beige emptiness **[2]**
17. **[ ]** Subtle motion or transition present on premium builds (or intentional stillness — not dead static template) **[2]**
18. **[ ]** Mobile: CTA and phone usable without pinching **[1]**
19. **[ ]** No invented stars/years/license/warranty; empty fields hidden **[3][4]**
20. **[ ]** No SiteForge / Launch Window / $750 mentions  
21. **[ ]** Imagery is designed/AI — not real contractor photos  
22. **[ ]** Positive, specific language (no “Tired of leaks?” as the H1) **[4]**
23. **[ ]** Attention ratio disciplined — page doesn’t compete with itself **[1]**
24. **[ ]** Looks agency-grade: contrast, whitespace, rhythm consistent **[1][2]**

**Fail fast examples:** mood headline with no offer; beige canvas; one boxed photo + caption; dark vague button; paragraph-only inclusions; zero trust; zero motion/hierarchy; invented claims.
